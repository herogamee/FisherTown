## Long-term Species Goal

ไม่ตั้งเป้า “ปลาทุกชนิดบนโลก” แบบตัวเลข marketing

เป้าหมายที่ดีกว่า:
สร้าง content pipeline ที่สามารถรองรับหลายร้อยถึงหลักพัน species โดย:
- taxonomy ไม่พัง
- art ไม่ generic
- habitat ไม่มั่ว
- licensing ตรวจสอบได้
- performance ยังดี

## Definition of Done for a New Species

Species จะเข้า production เมื่อ:
1. accepted taxonomy confirmed
2. native/introduced range confirmed
3. habitat confirmed
4. size model source available
5. visual reference legal checklist complete
6. art morphology reviewed
7. fight profile curated
8. bait guild mapped
9. conservation handling reviewed
10. localization/common names reviewed
11. data provenance stored
12. in-game spawn tested only in valid locations
