# FisherTown — Vision & Design Constitution

## High Concept

FisherTown คือเกม Cozy World Fishing ที่จำลองการเดินทางไปตกปลาในแหล่งน้ำทั่วโลก โดยใช้ปลาจริง ถิ่นอาศัยจริง และพฤติกรรมที่อิงธรรมชาติจริงเป็นฐาน แต่ห่อด้วยประสบการณ์ที่ผ่อนคลาย เล่นง่าย และไม่บังคับให้ใช้เวลานาน

ผู้เล่นควรสามารถ:
- เปิดเกมแล้วเริ่มตกปลาได้ภายในประมาณ 30–60 วินาที
- เล่นรอบสั้น 2–5 นาทีแล้วออกได้โดยไม่เสียความคืบหน้า
- เล่นยาวได้ถ้าต้องการล่าสถิติ สำรวจพื้นที่ หรือจัด Aquarium
- หยุดหลายวันหรือหลายสัปดาห์แล้วกลับมาเล่นต่อได้โดยไม่ถูกลงโทษ
- เรียนรู้เรื่องปลาและระบบนิเวศโดยไม่รู้สึกว่ากำลังอ่านตำรา

## Player Fantasy

ผู้เล่นเป็นนักตกปลาและนักสำรวจธรรมชาติจาก FisherTown เมืองฐานที่ค่อย ๆ เติบโตจากชุมชนเล็ก ๆ ไปเป็นศูนย์รวมของนักตกปลาจากทั่วโลก

เส้นทางชีวิตในเกม:
1. เรียนรู้การตกปลา
2. เก็บบันทึกชนิดปลา
3. สร้างสถิติส่วนตัว
4. เดินทางไปยังลุ่มน้ำและทะเลใหม่
5. สร้าง Aquarium / Museum / Research Center
6. ปรับปรุงท่าเรือ ร้านอุปกรณ์ บ้าน และเมือง
7. กลายเป็น World Angler ที่รู้จักธรรมชาติของปลาแต่ละภูมิภาค

## Target Experience

คำที่ต้องรู้สึกได้จากเกม:
- สบาย
- สดชื่น
- มีชีวิต
- อยากรู้อยากเห็น
- ภูมิใจเมื่อจับตัวใหญ่หรือพบชนิดใหม่
- ไม่เร่ง
- ไม่กดดัน
- ไม่กลัวพลาด

เกมต้องไม่กลายเป็น:
- เกมกดสุ่มตัวเลข
- เกม Energy ที่เล่นต่อไม่ได้จนกว่าจะรอ
- เกม Daily Streak ที่ทำให้ผู้เล่นรู้สึกผิด
- เกม Pay-to-Win
- เกมที่ปลาทุกชนิดมีพฤติกรรมเหมือนกัน
- เกมที่เอาปลาจากประเทศหนึ่งไปวางในอีกประเทศเพื่อเติมคอนเทนต์
- เกมที่ใช้ข้อมูลอนุรักษ์ผิดหรือชวนให้ล่าชนิดอ่อนไหวเพื่อเงิน

## Core Pillars

### 1. Short Session, Long Journey

หนึ่งรอบการตกปลาปกติใช้เวลาประมาณ 2–5 นาที
ปลาใหญ่หรือ Trophy Fight ควรจบภายในประมาณ 5–10 นาที

ทุกการกระทำสำคัญต้อง Auto-save:
- ก่อนเหวี่ยง
- เมื่อเหยื่อตกน้ำ
- เมื่อ Hook
- หลังจบ Fight
- หลังบันทึกปลา
- หลังซื้อ/ขาย/คราฟต์

ถ้าแอปถูกพักหรือปิดกลาง Fight:
- Freeze simulation เมื่อ browser background
- ถ้ากลับมาใน session เดิม ให้ Resume
- ถ้า state เสียหรือ session หมดอายุ ให้คืนผู้เล่นสู่จุดก่อนเหวี่ยงโดยไม่เสียเหยื่อหรือค่าความทนทาน

### 2. Real Fish, Readable Game

ข้อมูลข้างใต้สมจริง แต่ UI ต้องอ่านง่าย

ผู้เล่นไม่จำเป็นต้องรู้คำว่า benthopelagic หรือ anadromous เพื่อเล่นได้ แต่เกมสามารถแปลเป็นภาษาคน เช่น:
- ชอบอยู่ใกล้พื้น
- อพยพระหว่างแม่น้ำกับทะเล
- ชอบน้ำไหล
- ซ่อนตามไม้จมน้ำ
- ออกหากินกลางคืน

โหมด Encyclopedia จึงค่อยเปิดรายละเอียดวิทยาศาสตร์สำหรับคนที่อยากเรียนรู้

### 3. Fish Are Individuals

ปลาทุกตัวที่ติดเบ็ดไม่ใช่แค่ species + random weight

ปลาแต่ละตัวมี:
- species
- length
- weight
- condition
- energy
- hunger
- wariness
- local habitat
- fight temperament
- personal record eligibility
- capture history

ตัวที่ผู้เล่นภูมิใจสามารถถูกบันทึกเป็น Trophy Record พร้อมรูป สถานที่ เวลา สภาพอากาศ เหยื่อ และอุปกรณ์

### 4. World Atlas, Not Theme Parks

พื้นที่เกมต้องมาจากโครงภูมิศาสตร์จริง:
Continent → Country/Region → Basin/Sea → Waterbody → Habitat → Fishing Spot

ตัวอย่าง:
Thailand → Chao Phraya Basin → lowland river → deep pool / flooded margin

เราไม่จำเป็นต้องสร้างแผนที่ GIS 1:1 แต่ชนิดปลา คุณภาพน้ำ พืชพรรณ ภูมิอากาศ และโครงสร้างแหล่งน้ำต้องไปทางเดียวกับธรรมชาติจริง

### 5. No Hard FOMO

ระบบเวลาและฤดูใช้สร้างความหลากหลาย ไม่ใช่ปิดกั้นผู้เล่น

หลัก:
- Event สำคัญหมุนเวียนกลับมา
- ไม่มีรางวัลสำคัญที่หายถาวรเพราะพลาดวันเดียว
- Daily Mission เป็น Suggested Activities ไม่ใช่บังคับ
- Streak มีแต่โบนัสอ่อน ๆ หรือไม่ใช้เลย
- ปลาที่ออกกลางคืนสามารถพบผ่าน Expedition Time Window ที่ผู้เล่นเลือกได้เมื่อปลดล็อก ไม่ต้องรอเวลาจริงถึงเที่ยงคืน

### 6. Conservation-aware

ชนิดปลาอ่อนไหวหรือคอนเทนต์ที่เสี่ยงต่อการสร้างความเข้าใจผิดต้องมีกติกาเฉพาะ เช่น:
- Photo Encounter
- Research Tag
- Catch & Release
- ไม่ขาย
- ไม่ทำเป็นวัตถุดิบ
- แสดงข้อความความรู้แบบไม่สั่งสอน

สถานะอนุรักษ์ต้องใช้ข้อมูลที่มีสิทธิ์ใช้งานเชิงพาณิชย์อย่างถูกต้อง ห้ามนำข้อมูล IUCN API เข้าเกมเชิงพาณิชย์โดยไม่มีสิทธิ์

## FisherTown Hub

เมืองเป็นพื้นที่พัก ไม่ใช่ภาระบริหาร

สถานที่หลัก:
- Dock: เลือก Expedition / เรือ
- Tackle Shop: อุปกรณ์
- Bait Lab: เหยื่อและการทดลอง
- Aquarium: จัดแสดงแบบจำลองปลาที่ค้นพบ
- Museum: Fishdex / records / world map
- Research Center: Habitat knowledge / photo survey / tagging
- Workshop: ซ่อมและคราฟต์
- Market: เศรษฐกิจสำหรับชนิดที่เกมอนุญาต
- Home: เครื่องแต่งกาย ของสะสม Trophy
- Community Pier: social / async visitors / friendly records

## Tone

โลกของเกมมีความสมจริงในปลา แต่บรรยากาศภาพรวมอบอุ่นและสงบ

ไม่มี gore
ไม่มีการทรมานปลา
ไม่มีเสียงหรือภาพที่ทำให้ Fight ดูโหดร้าย
การปล่อยปลาคืนควรเป็นช่วงเวลาที่รู้สึกดีและได้รับคุณค่าทางเกมพอ ๆ กับการเก็บ

## Monetization Constitution

ขายได้:
- เสื้อผ้า
- Skin คันเบ็ด
- Skin เรือ
- ธีม FisherTown
- Aquarium decoration
- Emote / photo frame
- Cosmetic pass
- Expansion content ถ้าจำเป็น

ห้ามขาย:
- คันเบ็ดที่ทำลายสมดุล record
- ปลา Trophy สำเร็จรูป
- การเพิ่มอัตรา record แบบ pay-only
- ระบบบังคับเติมเงินเพื่อเล่นต่อ
- Loot box ที่มี power

## Success Definition

FisherTown สำเร็จเมื่อผู้เล่นสามารถพูดได้ว่า:
“ฉันเข้าไปตกปลาสักสองสามตัวก่อนนอนก็สนุก แต่ถ้ามีเวลาก็อยากเดินทางไปหาปลาที่ฉันยังไม่เคยเจอทั่วโลก”
