FisherTown v0.5 — Sunny Bay Playable Web

Live: https://herogamee.github.io/FisherTown/
Sunny Bay direct: https://herogamee.github.io/FisherTown/sunny-bay/
Classic v0.4: https://herogamee.github.io/FisherTown/?classic=1

Windows XAMPP3:
- Build artifact name: FisherTown-v0.5-Web
- Extract the ZIP, start Apache with XAMPP, run START-XAMPP.cmd from this build.
- The default page redirects to sunny-bay; Classic is available with ?classic=1.
- To install Sunny Bay without touching Classic, run sunny-bay/INSTALL-XAMPP3.cmd,
  which copies only that edition to C:\xampp3\htdocs\fishertown-sunnybay

Sunny Bay controls:
- Choose bait; hold/release Cast; wait for a bite; click HOOK!
- Hold and release Reel to keep tension in the safe band
- Catch the fish, then release it; records are saved in browser storage

Note: the approved mockup scene has been repurposed as a photo-based static
environment; interface buttons are real. Swimming fish/rod/water are not yet
fully production-rigged. Please test real iPhone/Android devices.
