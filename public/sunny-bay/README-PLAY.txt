FisherTown Sunny Bay v0.6 — Animated Fishing Game

เปิดเล่น Windows โดยไม่ติดตั้ง Node/npm:
1) เปิด START-WINDOWS.cmd ถ้ามี Python
2) หรือดับเบิลคลิก INSTALL-XAMPP3.cmd (ใช้ C:\xampp3)
3) Start Apache ที่ XAMPP Control Panel
4) เปิด http://localhost/fishertown-sunnybay/

บนมือถือที่อยู่ใน Wi-Fi เดียวกัน เปิด http://IP-คอมพิวเตอร์/fishertown-sunnybay/
(Windows Firewall ต้องอนุญาต Apache บน Private Network)

วิธีเล่น:
1. เลือกเหยื่อ ไส้เดือน/ลูกปลา/สปินเนอร์
2. กดค้าง "เหวี่ยงเบ็ด" ดูคันเบ็ดโค้งเอนตามแรงกด ปล่อยเพื่อเหวี่ยง
3. ดูปลาที่ว่ายเข้าหาทุ่นจริง (ตำแหน่งปลาเป็นตัวละครใน Canvas)
4. เมื่อปลากินเหยื่อ กด HOOK! ให้ทัน
5. กดค้าง "ดึงสาย" แล้วปล่อยเมื่อแรงตึงสูง; อย่าปล่อยหย่อนนาน
6. รับผลการจับปลาพร้อมชื่อ/ขนาดและปล่อยปลา สถิติเก็บใน LocalStorage
7. แตะบริเวณน้ำเพื่อปรับตำแหน่งเป้าหมายในรอบต่อไป

ความแตกต่างจาก v0.5:
- ไม่มีปลา/คันเบ็ด/ทุ่นที่แปะค้างอยู่ในฉากหลัง
- ปลาทะเลสไปรต์โปร่งใสแยกจากฉาก (14 fish actors, 5 styles)
- AI เลือกปลาที่เข้าหาเหยื่อตามชนิดและระยะ ไม่ใช้แค่เวลาสุ่มกัด
- คันเบ็ด/สาย/ทุ่นเป็น Canvas ที่เคลื่อนไหวตลอด งอเมื่อติดปลา/กดเหวี่ยง
- ภาพฉากพื้นน้ำสะอาดใช้ synthetic caustics / coral ตามแนวภาพต้นแบบ
- เมนูและปุ่มทั้งหมดเป็น HTML ที่กดได้จริง

ภาพต้นแบบที่เคยส่งมาใช้เป็น art reference เท่านั้น ไม่ใช่ background ของเกม
ภาพปลาต้นทางเป็นงานสร้างประกอบที่แยกสไปรต์จากภาพคอนเซปต์ ไม่ใช่ข้อมูลวิทยาศาสตร์ที่ได้รับการรับรอง

ทดสอบส่วน fish AI + cast/HOOK/rod ด้วย Node: npm test (ไม่มี dependencies)
